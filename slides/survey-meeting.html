Dashboard

  • Interactive dashboard for international RSE survey data

  • All countries in one place

Quarto book (new)

  • Lives in GitHub
  • One question at a time, with its question text
  • Ready to share: meetings, reports, appendices
  • Custom analysis, groups, visualisations, etc.
  • Reproducible, Open source, Python 3.x

Structure of the book

Folder structure

data/2026/             survey CSV files (not in git)
src/rse_survey_report/
  config.py            Nordics, groups, topics
  codebook.py          question type, answers, order
  plotting.py          plot_choice, plot_agreement, ...
  book.py              writes one chapter per question
book/
  _setup.qmd           loads the data for each chapter
  chapters/            generated chapters
Makefile               make book, make slides, make test

Contents

  • 66 chapters, one for each question.
  • Current template for chapters has four sections:
    • Nordics, By age group, Within Nordics, Between countries

Use the book for your own analysis

Task Edit Then run
Render the book Put the CSV files in data/2026/ make book
Change a plot A function in plotting.py make test, then make book
Change a group AGE_GROUPS or COMPARE_GROUPS in config.py make book
Add a section to each chapter chapter_qmd() in book.py make book
  • make book writes the chapters again and renders it to book/_book/.

RSE Organisation (II)

Discussion

  • Other activities. Respondents want to spend less time on “other activities”. Besides research, software development, teaching and management: what else takes your time?
  • Labour market. 16% disagree that their experience is in demand. Which skills or experience are missing to succeed on the job market?
  • Promotion. Promotion routes seem unclear. What is your experience? What would make the routes clearer?
  • DOIs for software. 20 of 25 respondents never create a DOI for their software. Why not? Is it not relevant for your software, or did you not know it is possible?
